\# Container Image Vulnerability Scanner



\## Project Overview



This project scans Docker container images for security vulnerabilities using Trivy and CVE databases.



The scanner helps DevOps teams identify vulnerable packages before deployment.



\## Objectives



\- Scan Docker images

\- Detect CVEs

\- Generate vulnerability reports

\- Automate scanning process

\- Integrate with CI/CD pipelines



\## Tools Used



\- Docker

\- Trivy

\- Python

\- Git

\- GitHub Actions (Future Sprint)

\- Prometheus (Future Sprint)

\- Grafana (Future Sprint)
