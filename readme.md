# Sprint 3 – Security Reporting & Slack Notifications

## Overview

Sprint 3 focuses on enhancing the DevSecOps security pipeline by introducing automated vulnerability reporting and real-time Slack notifications.

The goal is to provide immediate visibility into security findings generated by Trivy scans and make vulnerability reports easily accessible for developers and security teams.

---

## Objectives

* Generate consolidated vulnerability reports automatically.
* Summarize findings from multiple Trivy scan reports.
* Create human-readable HTML reports.
* Send security scan summaries to Slack.
* Integrate reporting and notification capabilities into GitHub Actions.

---

## Solution Architecture

```text
Developer Push
      │
      ▼
GitHub Actions Security Pipeline
      │
      ├── Gitleaks Secret Scan
      ├── Trivy Filesystem Scan
      ├── Container Image Scans
      │
      ▼
Report Generator
      │
      ├── summary-report.json
      └── consolidated-report.html
      │
      ▼
Slack Notification
      │
      ▼
Security Team
```

---

## Components Implemented

### 1. Report Generation

A Python script was developed to process Trivy JSON reports and generate consolidated vulnerability summaries.

**Script:**

```text
scripts/report_generator.py
```

**Generated Reports:**

```text
reports/summary-report.json
reports/consolidated-report.html
```

The report generator performs:

* Parsing of Trivy scan reports
* Extraction of vulnerability counts
* Severity classification
* Summary generation
* HTML report creation

---

### 2. Slack Notification Integration

A Slack Incoming Webhook was configured to automatically notify stakeholders after every successful security scan.

**Script:**

```text
scripts/slack_notify.py
```

Notification includes:

* Report Name
* Critical Vulnerabilities
* High Vulnerabilities
* Scan Summary

---

### 3. GitHub Actions Integration

The security workflow was extended to automate report generation and Slack notifications.

Workflow steps:

1. Checkout Repository
2. Run Gitleaks
3. Execute Trivy Filesystem Scan
4. Build Container Images
5. Perform Container Image Scans
6. Generate Security Reports
7. Send Slack Notification
8. Upload Security Artifacts

---

## GitHub Secrets

To securely manage Slack credentials, GitHub Actions Secrets were used.

Configured Secret:

```text
SLACK_WEBHOOK_URL
```

This prevents sensitive information from being stored in source code.

---

## Generated Artifacts

The workflow automatically uploads:

```text
backend-report.json
frontend-report.json
admin-report.json
trivy-fs-report.json
summary-report.json
consolidated-report.html
```

These artifacts can be downloaded directly from GitHub Actions.
